# Fourier_tranform_in_image_and_video-processing
A python project demonstrating the application of Fourier Transform in image and video processing using openCV,Numpy and Matplotlib.
The objectives are as below;
To understand Fourier Transform .
To apply Fourier Transform in image processing.
To apply Fourier Transform in video processing.
To analyze image and video frequency spectra. 

The libraries and tools used;
python 
Google colab
OpenCV
Numpy 
Matplotlib 
Github 

How it works 
image processing 
An image is uploaded. 
The image is read and displayed as the original image 
The image is converted into grayscale 
2D Fourier Transform is applied using Numpy 
Frequency components are shifted to the center 
The magnitude spectrum is calculated and displayed.

Video processing 
video  is uploaded 
OpenCv opens the video 
A frame is extracted from the video 
The extracted frame is displayed and converted into grayscale 
Fourier Transform is applied to the Frame.
The magnitude spectrum is calculated and displayed. 
displaying frequency spectrum.

conclusion 
This shows how Fourier Transform converts image information
into the  frequency domain for analysis.
